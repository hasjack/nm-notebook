Install: python3 -m pip install numpy scipy matplotlib mpmath
Run: python3 ordinary_counts.py

Keep ordinary_counts.py and full_test_results.json together.
The cached roots were computed in the preceding full_test.py experiment.
The reconstruction uses an exact owner-count anchor at x=100 and exact higher-prime-power corrections.
It compares ordinary prime counts in classes 4 and 11 modulo 15, including the unsmoothed residual around an anchored Li(x)/4 baseline.
Root lists are numerical, not certified complete.
