## Compression definition

**compression_ratio** = `digits(q) / max(1, n_kills)` — decimal digits of \(q\) per kill-receipt (witness triple \((k,\mathrm{class},r)\)). When `n_kills=0` (\(K_{\mathrm{cert}}=2\), floor-tight), ratio equals `digits` (treated as floor-tight / formally infinite). This is the hunt metric alongside raw \(K_{\mathrm{cert}}\); **not** rank chasing.

## Hire door rules

- \(m_0(p) = p+1\) if \(p\equiv 1\pmod{3}\), else \(p-1\`.
- Admissible \(k\equiv 2\) or \(4\pmod{6}\); class A: \(p=kq-1\), class B: \(p=kq+1\).
- Class ↔ \(k\) **flips** when \(q\equiv 2\pmod{3}\) (else \(r=3\) kills all).
- \(K_{\mathrm{cert}}\) = first admissible \(k\) surviving all \(r\le B\).
